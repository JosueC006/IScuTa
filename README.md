# IScuTa
IScuTa é uma healthtech que combate ISTs (HIV, sífilis) entre jovens de 15 a 34 anos com uma jornada de prevenção gamificada e privada. Ensina sobre PrEP e PEP via vídeos e quizzes, tem chatbot confidencial, geolocalização para postos de saúde e agenda de exames. Estudos do PubMed apontam +40% de adesão com gamificação, aproximando o jovem do SUS.
